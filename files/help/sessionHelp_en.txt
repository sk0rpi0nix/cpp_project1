add <NAME> <SERNAME> <LASTNAME> <COURSE> <MARK1> <MARK2> <MARK3> <MARK4>
    Add new user with fields NAME,SERNAME,LASTNAME,COURSE,MARK1,MARK2,MARK3,MARK4.

update {NAME | _} {SERNAME | _} {LASTNAME | _} {COURSE | _} {MARK1 | _} {MARK2 | _} {MARK3 | _} {MARK4 | _}
    Update user's fields or leave them unchanged.

get <ID>
    Get user by ID.

remove <ID>
    Remove user by ID.

list
    List all users in database.

task <COURSE>
    Get average marks value by users' COURSE.

sort {FIELD_INDEX | MARKS_INDEX.MARK_INDEX} {asc | desc}
    Sort database by FIELD_INDEX in asc or desc order. If MARKS_INDEX chosen, ".MARK_INDEX" must be specified. 

file {text | binary} {read | write} <FILE_NAME>
    Read or write to binary or text file in "files/inbox/" directory.

exit
    Exit session.
